## Descrição e funcionalidade do projeto:
Nesta aplicação haverá como adicionar nomes de pessoas (amigos) para realizar um sorteio. Assim que os nomes são acrescentados eles aparecerão na tela logo abaixo do campo input; ao sorteio, apenas um nome aparecerá como resultado acima do botão 'sortear amigo'.
